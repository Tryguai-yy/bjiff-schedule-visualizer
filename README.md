# 北影节排片可视化

把北影节影单从一张难以浏览的排片表，重新组织成一个更接近电影媒体首页与流媒体选片体验的静态页面。

## 项目背景

电影节排片通常首先以 Excel 或表格形式发布。它完整、准确，但并不天然适合“浏览”这件事: 观众往往不是先带着唯一目标检索某一场电影，而是在日期、单元、影院、导演回顾、放映密度和临时兴趣之间来回切换，慢慢形成自己的观影路线。

这个项目的出发点，就是把北影节影单从“信息表”变成“可游览的片单界面”。它保留原始排片的结构，同时加入更适合观看与发现的组织方式，让用户可以先感受展映气质，再进入具体场次。

## 项目特点

- 以电影 app / 流媒体首页的方式重组北影节排片信息
- 支持按日期、单元、看点筛选影片
- 支持搜索电影名、英文名、导演回顾单元和影院
- 提供展映概览、精选推荐和更适合浏览的卡片布局
- 优先补充豆瓣简介、评分和海报信息
- 海报缺失时自动回退为文字海报

## 数据说明

项目数据由北影节排片表整理生成，最终输出为仓库中的 `data.js`，页面本身直接读取这份静态数据进行展示。

如需重新生成数据，可将排片 Excel 放到项目根目录，默认文件名为 `bjiff_schedule.xlsx`，然后运行：

```bash
python3 scripts/generate_bjiff_data.py
```

如果 Excel 文件名或位置不同，也可以显式传入：

```bash
python3 scripts/generate_bjiff_data.py /path/to/your-schedule.xlsx
```
